## 1.2 Useful tools

There are several types of tools that you will want to have to work with this 
program (in relative order of importance):

   * An ASCII text editor for preparing and modifying input files.

   * A picture viewer for viewing images.

   * An image processing program for translation between Targa and
     some other format.

   * An animation generator that will take a series of Targa images
     and produce an animation file.
                                 
   * A media player for playing an animation on the screen eg Media Player Classic HC.

Polyray.  These have been somewhat arbitrarily divided them into categories, with no
